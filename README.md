## 约定

- “平稳”均指宽平稳。
- 涉及求导时按均方可微处理，并假设所需二阶矩有限。
- 互相关统一取

  $$R_{XY}(\tau)=\mathrm{E}\left[X(t)Y(t+\tau)\right].$$
